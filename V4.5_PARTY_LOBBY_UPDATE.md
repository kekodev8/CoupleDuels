# CoupleDuels V4.5 — Neon Party Lobby + Party Mode

This is the deployable project based on CoupleDuels V4.3. It preserves the V4.3 home page and all original 11 game modes.

## Lobby changes
- Actual live synchronized lobby uses the approved V4.4 artwork and player-card layout.
- Players can select from six characters with separate Ready / Not Ready expressions.
- Backgrounds are independently selected inside the Edit Character dialog.
- Players can change their own mood; the displayed image updates to that mood.
- Players can change their own optional drink counter.
- Scores and wins are no longer hard-coded sample values. Wins update once, after a completed game, for the duration of that room.
- Game browser uses **complete game artwork without additional thumbnail frames**, and each player can vote by clicking an image.
- Both votes must match and both players must be Ready before the host can start. The Host starts after consensus; host-only mode selection is replaced by voting in the lobby UI.
- The custom Party Mode artwork, voting banner, Browse Games heading, heart bolt and Start button are integrated as real images.

## Party Mode
- 16 randomized, synchronized mini-rounds themed after the existing 11 game modes, including at least one of each theme.
- The initial version uses short-form mechanics (matching, quizzes, rock-paper-scissors and reaction heats), **not 16 complete instances of the original game engines**.
- Shared authoritative scores, reveal and Ready-to-continue synchronization on both phones, and a winner after the final round.
- At the end, the winner may suggest a challenge. The other player can select an optional drink, choose the suggested challenge, or skip.

## Installation
1. Unzip the archive.
2. Upload the **contents** of `sip-happens/` into the root of your CoupleDuels GitHub repository.
3. Commit and let Render redeploy the existing Node project.
4. Keep Render's Root Directory empty. Existing `npm start` / `node server.js` remains the launch command.
5. On two phones, create and join one room, choose avatars, Ready both players, vote for Party Mode on both phones, then start.

## Notes / known limits
- Room profiles, drinks, mood, and win counts are stored **in room memory**, not a permanent database. Starting a new room resets these values.
- This archive was syntax-checked and passed automated tests including a two-player simulated socket flow. A real browser screenshot and live Render/two-phone test were not completed here.
- Full client assets are retained under `public/lobby44/`, as selected in the artwork preview.
- No changes were deployed automatically to the public site.
