# CoupleDuels V4.7 — Standalone Quick Draw

The standalone **Quick Draw** selection now runs the same two-player drawing mini-game as V4.6 Party Mode, replacing the previous reaction-tap Western duel.

- Four drawing heats, **10, 8, 6, 4 seconds**.
- Players alternate artists. A random secret word is shown only to the artist during drawing.
- The sketch streams live to the other phone via Socket.IO. After the drawing period, the guesser has 12 seconds to enter guesses.
- Correct guess: **3 points for the guesser, 2 for the artist**.
- Shared pause/resume pauses the deadlines, and a winner is shown at the end of heat 4.
- Browser mouse/touch/pointer support; same scoring and drawing logic from party.js; Party Mode remains intact.

## Deployment

Upload the **contents of the `sip-happens` directory**, replacing the previous project code, and redeploy on Render (root directory blank). No new npm dependencies.
