# CoupleDuels V4.8 — Quick Draw stability, ink, undo

- Standalone and Party Mode Quick Draw share four 15 / 11 / 7 / 4-second drawing heats.
- A new pointer handler starts a fresh independent stroke on each finger/mouse press, properly releases it, and allows another stroke after lifting a finger or interrupted focus.
- Server-authoritative ink budget of 3.2 normalized canvas lengths per heat; drawing consumes ink by distance, not by number of events.
- Undo removes only the newest touch/mouse gesture (everything since the last pointerdown), and restores the ink used by that gesture.
- Drawing and undo are synchronized to both phones, with server-side checks restricting them to the artist.
- A larger labeled guess entry and button replace the cramped inline guess form.
- Ink is reset for each heat; guessing remains 12 seconds. V4.7 scoring is unchanged.
- A complete project copy is in the sip-happens directory, ready for deployment to Render.
