# CoupleDuels V4.6 — Party Mode mini-game update

**Party Mode only**: the Kart Clash round is no longer a 3-button route-choice question. Both players now compete in a 15-second, server-synchronized three-lane kart-dodging sprint. Use LEFT/RIGHT to avoid traffic cones and collect star pickups. Hits reduce the awarded round score; pickups increase it. Race controls and scores remain linked to each player's own room identity.

**Quick Draw within Party Mode** is now a live shared drawing canvas. This one Party Mode round contains four timed drawing heats at **10 seconds, 8 seconds, 6 seconds, and 4 seconds**. Players alternate drawing; only the drawer sees the random word. The other player sees the strokes live and has twelve seconds after each sketch to type a guess. Correct guesses award 3 points to the guesser and 2 to the artist. Other than guessing the word, no AI drawing recognition is used. A round-end scoreboard follows the fourth heat.

Both changes use the existing Socket.IO room protocol, keep Party Mode's total at 16 rounds, support shared pause/resume for deadlines, and preserve the rest of the lobby and eleven standalone game modes. The standalone Kart Clash and Quick Draw Duel modes are not changed in this release.

Run `npm test` for unit and simulated room integration checks. After deploying, test both phones simultaneously—especially canvas drawing on iOS Safari, drawing timer transitions, race steering, pause/resume, and returning to lobby after 16 rounds. Live iPhone-to-Android play was not verified in this environment.

To deploy, upload the contents of `sip-happens` to the repository root and allow Render to redeploy with the existing configuration.
